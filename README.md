# PlateShare

A mobile food-sharing platform connecting excess-food suppliers with buyers, delivery partners, and charity organisations. I primarily developed the buyer module and fully implemented the organisation and delivery flows.

## What this repository covers

- Four connected user roles
- Food discovery, donation, and order workflows
- Maps, media, email, and live order status
- Stripe-backed payments
